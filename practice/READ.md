# Practice & Sandbox Scripts

This directory contains experimental scripts, learning exercises, and concept testing for network automation. 

> **Note:** The scripts here are built for hands-on practice, testing Netmiko/API functionalities, and honing automation skills. They are not intended for production environment deployment without refactoring and testing.

---

### 🎯 Key Focus Areas
* SSH connection handling with **Netmiko**
* Parsing CLI output (`show ip int brief`, `show version`)
* Basic API calls and JSON parsing
* Error handling and environment variable usage
